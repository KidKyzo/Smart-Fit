# SmartFit 🏋️‍♂️

SmartFit is a comprehensive fitness and nutrition tracking application built with modern Android development practices. It aims to help users maintain a healthy lifestyle by providing tools to track exercises, monitor nutritional intake, and visualize their progress.

## 🌟 Key Features

### 1. Exercise Discovery
- Access an extensive database of exercises categorized by body parts (Biceps, Cardio, Legs, etc.).
- Powered by the **ExerciseDB API**, providing detailed instructions and information for each workout.

### 2. Nutritional Tracking
- Search and track food items to monitor daily calorie and nutrient intake.
- Integrated with the **FatSecret Platform API** for accurate nutritional data.

### 3. Activity Logging
- Keep a digital log of your physical activities and workouts.
- Save progress locally for offline access and historical tracking.

### 4. Progress Visualization
- Intuitive **Daily Calendar Graphs** to visualize activity frequency and consistency over time.
- Dashboard overview of daily goals and achievements.

### 5. Personalized Experience
- Secure user authentication (Login/Signup).
- Customizable profiles.
- Dynamic theme support (Light and Dark modes) using **Material Design 3**.

## 🎯 Target Audience
SmartFit is designed for fitness enthusiasts, beginners looking for guidance, and anyone committed to improving their physical health and nutritional habits.

## 🛠 Technical Stack
- **Language:** Kotlin
- **UI:** Jetpack Compose with Material Design 3
- **Architecture:** MVVM (Model-View-ViewModel)
- **Local Database:** Room
- **Networking:** Retrofit & OkHttp
